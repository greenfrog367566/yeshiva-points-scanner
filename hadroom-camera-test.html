1 · Camera

Camera names are hidden until you grant permission once.

Zoom and sweep controls appear here once the camera is open — press Start. They only exist if the camera hands pan/tilt/zoom to the browser, and Chrome asks for a separate "pan, tilt & zoom" permission the first time. If the camera does not offer them, this spot says so instead.

What sweeping is for. Zoom buys distance by cropping, so it sees fewer boys at once. Sweeping pans the camera across the room and adds up what it found at each stop, buying that coverage back with time instead of field of view — one full pass is a roll call of the room rather than a snapshot. Zoom in until the back row reads, then set enough stops to cover the seats. Roughly one stop per 1× of zoom, plus one for overlap.
Link Controller bridge — not connected

The Link's zoom is a standard control the browser can drive directly, but its gimbal is a vendor command no browser can reach. Insta360's own Link Controller app can, and it leaves a local WebSocket open for its phone remote — this talks to that. In Link Controller, turn on Remote control (“connect your mobile phone to remotely control the device”) so its QR code is actually on screen — that panel is the only thing that shows one. Then press “Read the code from a window…” and pick the Link Controller window: the page reads the code straight out of it at full resolution and connects itself — nothing to squint at, and no screenshot to save. Sharing is used only to find that code, and stops the moment it does. Failing that: hold the code up to the camera, paste or drop a screenshot, or type the port and token in.

Two separate levers on range, and it matters which one you move. Detect width is how wide the frame is scaled to before detection — the default 1920 keeps a 1080p camera at full resolution (it never upscales: a smaller feed is used as-is). Lowering it saves CPU but throws away exactly the pixels that decide a distant read. Zoom makes the codes bigger by cropping, so it buys range at the cost of seeing fewer boys. Keep detect width at native first, and spend zoom on what is still missing. "Smallest code" below is the shortest side, in detect-frame pixels, of the smallest code seen this pass — it is the number that decides whether a code reads, and what auto-zoom steers on.

Printable test sheet

Print at 100% / actual size — not "Fit to page", or the measured size is meaningless. The 1-inch bar at the bottom of the sheet is there to check that with a ruler before trusting any distance result.

Lower error correction means fewer, larger squares in the same physical area, which usually reads from further away. Higher correction survives glare and creases better. Worth testing both before settling on a card.

1 inch — measure this. If it is not exactly 1", the printer scaled the page and the code sizes are wrong.
