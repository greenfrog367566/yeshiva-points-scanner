Wand detection prototype — not wired into the game

1 · Generate wand labels

Layout targets the generic 2"×2", 20-per-sheet US-Letter label grid (4 columns × 5 rows, e.g. OnlineLabels OL330 and equivalents — this is not Avery's own 22806 template, which is actually 12-per-sheet; see the report notes for why this grid was used instead). Print at 100% / actual size ("Fit to page" will throw off the alignment) with margins set to "None" in the print dialog. The dashed cell outlines are a screen-only alignment guide and do not print. Each marker's ID is the wand's identifier — the same number the Live Scanner tab reports back.

1 · Camera

Camera names are hidden until you grant permission once.

Requests the highest resolution the camera offers, up to 4K, and falls back to 1080p then to whatever the browser grants if that's refused. Detect width is the separate lever that controls detection cost — it downsamples the frame handed to the detector (never upsamples); lower it if the passes/sec stat below is too low for your marker density, at the cost of range on small/distant markers.
