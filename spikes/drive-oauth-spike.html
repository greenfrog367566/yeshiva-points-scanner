Drive backup spike — tier 2 custody

docs/Data_Custody_Decision.md Q5 · issue #218 · next item in docs/NOW.md

1 · Setup (do this once)

  1. Create a throwaway project at console.cloud.google.com.
  2. Enable the Google Drive API (APIs & Services → Library → Drive API).
  3. OAuth consent screen → External. Add scope https://www.googleapis.com/auth/drive.file — it will be listed as non-sensitive, which is the whole point: no verification review. Add yourself as a test user. Leave it in testing mode.
  4. Credentials → Create OAuth client ID → Web application. This page uses a redirect flow, so both of these must be registered exactly as shown — copy them from here rather than typing them:
    No client secret is needed — the browser token flow doesn't use one.
  5. Paste the client ID into CLIENT_ID at the top of this file's script, or into the box below to try it without editing:

The client ID is not a secret — it identifies the project and authorises nothing on its own, the same property Firebase API keys have. The redirect URI must match character for character, which is why this page computes it for you instead of asking you to guess it.

3 · Run the steps in order

The step that matters is ⑤, and then ⑥ followed by ③. Everything before them only proves the API works, which was never in doubt. ⑤ asks whether the app can quietly get a new token an hour into a lesson without interrupting the rebbi. ⑥ then kills the token for real, so ③ has to recover from a genuine 401 rather than a simulated one — that is the exact moment a backup would silently stop working in a classroom. Run the whole thing again on a shared/logged-out Chromebook; a laptop where you are permanently signed into Google is the easy case and will tell you almost nothing.

5 · Findings — fill this in after running it

  • Does silent re-auth work on your own laptop? untested
  • Does it work on a shared Chromebook, signed out of Google? — this is the real question, and it has to be answered by hand.
  • If it fails, how many clicks does recovery take? One consent click is fine. A full sign-in mid-lesson is not.
  • Does the failure announce itself? A backup that silently stops is worse than one that never started — the staleness nudge in docs/Daily_Backup_Spec.md is the backstop, so confirm it would actually fire.

Write the answers into spikes/README.md when you have them. A spike whose results live only in someone's memory has failed.
