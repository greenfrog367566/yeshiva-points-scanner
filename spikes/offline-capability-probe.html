This is a diagnostic, not part of Menchmark. It stores nothing, changes nothing, and touches no class data. It answers one question: what can an offline rebbi's machine actually do? Open it the same way your rebbeim open their offline copy — by double-clicking the file — and it will report on that exact setup.

Offline capability probe

Run this twice: once by double-clicking the file (a file:// page, which is what most offline rebbeim are on), and once served over http://localhost. The answers differ, and the difference is the point.

1 · Where am I running?

2 · Can anything back up automatically?

showDirectoryPicker is the one that matters. It is how a folder backup would write to disk without asking every time. If it is missing here, the automatic local-backup idea cannot reach this machine at all.

3 · Does a folder permission actually survive?

The real question is not whether you can pick a folder once — it is whether the app can still write to it tomorrow, without asking again. Pick a folder, then close this page, reopen it, and press Re-check.
