      Import questions — Kahoot-style CSV

      One question per row: Question, Answer A, Answer B, Answer C, Answer D, [time], Correct — where Correct is 1–4 (or A–D). It's the Kahoot quiz-spreadsheet layout, so a Kahoot export drops straight in. Header row fine; the time column is ignored.

      Make an AI prompt — for ChatGPT, Gemini or Claude
